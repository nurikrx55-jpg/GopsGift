# GopsGift

Telegram Mini App: тёмная тема, нижняя навигация из четырёх вкладок, карусель
баннеров на главной и витрина подарков.

Фронт — статика без сборки. Сервер — несколько функций Vercel в `api/` и
база Upstash Redis: в ней витрина, баннеры, задания, люди и их счета.

## Структура

| Файл | Назначение |
| --- | --- |
| `index.html` | разметка, подключение `telegram-web-app.js` и рендерера Lottie |
| `style.css` | тёмная тема, навигация, карусель, карточки подарков |
| `app.js` | Telegram SDK, вкладки, карусель, витрина подарков |
| `store.js` | откуда приложение берёт содержимое: сервер или запасной файл |
| `admin.html`, `admin.css`, `admin.js` | админка |
| `api/boot.js` | заход в приложение: витрина, счёт и отметка в списке людей |
| `api/admin.js` | всё, что умеет админка |
| `api/file.js` | анимации и картинки, загруженные из админки |
| `api/_lib/` | база, проверка подписи Telegram, данные |
| `data/content.json` | стартовое содержимое и запасной вариант без базы |
| `home/` | картинки баннеров карусели |
| `gifts/` | анимации подарков и иконка звезды |
| `fonts/` | SF Rounded |

## Сервер и админка

Содержимое живёт в Redis, а не в коде. На заходе приложение шлёт на
`/api/boot` подпись Telegram (`initData`); сервер её проверяет, отмечает
человека в списке и отдаёт витрину вместе с его счётом. Правка в админке
видна всем на следующем заходе.

Проверка подписи — только на сервере. Нужен токен бота в переменной
окружения `BOT_TOKEN` (или `BOT_ID` — тогда проверяется Ed25519-подпись
Telegram без токена). Админ — id `8387706094`; список меняется переменной
`ADMIN_IDS` через запятую.

Профиль из Telegram (`gg:user:<id>`) пишет только заход в приложение, а счёт
(`gg:acct:<id>`) — только админка: так заход не может затереть свежую правку
админа старым значением.

Анимации из админки хранятся сжатым `.tgs` — он в десять раз меньше json — и
отдаются через `/api/file` с вечным кэшем: адрес у каждой загрузки свой, и
повторно файл отдаёт CDN, а не база. Баннеры админка ужимает в браузере до
ширины слайда и шлёт в WebP.

Пока база не подключена, приложение не ломается: `/api/boot` отвечает 503, и
содержимое берётся из `data/content.json`. Админка в этом случае показывает,
что осталось подключить.

На первом запросе к пустой базе в неё переносится `data/content.json` и счета
из `api/_lib/presets.js`.

## Карточка подарка

Подарки приходят с сервера одним списком. Витрина (`GIFTS`) и подарки
пользователя (`OWNED`) ссылаются на **те же записи**, а не на копии — поэтому
плашка редкости не может разойтись: купленный подарок показывает в профиле
ровно ту же ленту, что была на витрине. Класть в `OWNED` копии нельзя, иначе
смысл теряется.

Поля записи: `art` (путь к анимации), `price`, `badge` (надпись на ленте),
`kind` (цвет), `left`/`total` (наличие), `owner`, `status`, `note`.

Цвета лент по редкости: `rare` зелёная, `epic` фиолетовая, `legend` жёлтая.
Только заливка, без обводок.

Анимации приходят от Telegram в формате `.tgs` — это **gzip поверх Lottie-JSON**.
Браузер такое не читает, поэтому файл распаковывается заранее:

```bash
gunzip -c gifts/gamepad.tgs > gifts/gamepad.json
```

Исходный `.tgs` лежит рядом с распакованным `.json` — грузится в браузер
только второй. Отдаётся он уже сжатым: Vercel включает gzip сам, так что
по сети идут те же ~30 КБ.

Рисует анимацию `lottie_light_canvas` с CDN: canvas быстрее SVG, когда
карточек на экране много, а выражения в `.tgs` запрещены самим форматом —
облегчённой сборки хватает. Анимация заводится, когда её контейнер показался на
экране, проигрывается **один раз** и замирает на последнем кадре: витрина не
должна дёргаться без остановки. В листе анимация, наоборот, зациклена.

Ждать появления на экране обязательно, и дело не только в экономии: у скрытого
блока нулевой размер, и lottie нарисует canvas шириной 0, который сам потом не
пересчитает. Именно так и вышло с анимацией в «пусто» — вкладка профиля при
старте скрыта. `playWhenSeen()` заводит плеер только когда у элемента появился
размер.

Если включён режим «уменьшить движение», карточка сразу переводится на
последний кадр. Просто не запускать её нельзя: композиция начинается с 60-го
кадра, и нулевой пустой — осталась бы белая плашка.

## Карточка крупным планом

Тап по подарку поднимает нижний лист. Поля берутся из той же записи в `GIFTS`:
`note` — подпись под названием, `left` и `total` — остаток, `status` — строка
статуса. Нет `left`/`total` — шкала просто не показывается.

Закрыть можно четырьмя способами: утянуть вниз, системной стрелкой «назад»
(`tg.BackButton`, показывается на время открытого листа), тапом по фону и Esc.
Своей кнопки-крестика нет.
Порог — 110 px (но не больше четверти высоты листа) либо рывок быстрее
0.7 px/мс; не дотянул — лист возвращается.

Чтобы жест не отбирал браузер, `touch-action` расставлен вручную: у шапки и
подложки с подарком — `none`, они всегда работают ручкой; у прокручиваемой
части — `pan-y`. Когда содержимое уместилось целиком, `app.js` вешает на неё
`is-static`, и ручкой становится весь лист. Без этого браузер забирал жест
себе на полпути, слал `pointercancel`, и лист прыгал обратно вверх.

Шкала — это сам остаток: кончается подарок, кончается и полоска. У заливки есть
`min-width: 6px`, иначе одна штука из тысячи схлопнулась бы в невидимую линию;
при нулевом остатке минимум снимается и полоски нет совсем. Ниже 10% остатка
шкала и приписка становятся янтарными.

Рядом с кнопкой покупки стоит счётчик штук. Выше наличия он не поднимается, и
цена в кнопке пересчитывается на лету.

Ориентация заблокирована через `lockOrientation()` — витрина и лист свёрстаны
под вертикаль, в ландшафте они ложатся набок. Метод из Bot API 8.0, на старых
клиентах пропускается.

Анимация в листе — отдельный экземпляр Lottie: создаётся при открытии и
уничтожается при закрытии, чтобы не копить плееры за спиной.

## Профиль

Вкладка собирается в `initProfile()` из того, что отдаёт Telegram
(`tg.initDataUnsafe.user`): аватар берётся из `photo_url`, имя — из `username`,
иначе из имени и фамилии, идентификатор — из `id`. Тап по иконке рядом с ним
копирует его в буфер, даёт вибрацию успеха, на секунду красит иконку зелёным и
поднимает сверху уведомление «ID скопирован».

Иконка намеренно не фокусируется: с `tabindex` браузер рисовал вокруг неё синюю
рамку после нажатия. Копирование идёт через `navigator.clipboard`, а если его
нет или он отказал — через скрытое поле и `execCommand`. Оба пути требуют
настоящего нажатия: синтетический клик из консоли браузер не считает действием
пользователя и копирование отклоняет.

**Вне Telegram ничего этого нет.** В браузере показывается «Гость», прочерк
вместо идентификатора и кружок с первой буквой вместо фотографии — проверять
вкладку по-настоящему нужно внутри клиента.

Ник и id — ровно те, что отдаёт Telegram. Золотой ник и галочку после него
выдаёт админка; признак приходит с сервера вместе со счётом, подменить его у
себя в браузере нельзя.

Балансы звёзд и купонов живут в общей шапке (`.hdr`, фиксирована сверху) и
приходят с сервера. Подарки пользователя — в `OWNED` с разделами `gifts` и
`nft` под переключатель.

Пустой раздел показывает анимированный стикер, надпись «Нет подарков(» и кнопку
с логотипом приложения, которая уводит на витрину. Логотип взят со splash-экрана
и вынесен в спрайт как `<symbol id="logo">`, чтобы не дублировать пути.

Переключатель — капсула, которая едет за `--prf-index`, тем же приёмом, что
подложка в нижней навигации.

## Две карточки крупным планом

Листов два, и механика у них общая — `createSheet(root, hooks)` берёт на себя
выезд, закрытие, перетаскивание, системную «назад» и блокировку прокрутки
сцены. Наполнение передаётся крючками `fill` / `opened` / `closed`, так что
добавить третий лист — это разметка плюс один вызов.

- **Покупка** открывается с витрины: счётчик штук, цена, кнопка покупки.
- **Купленный подарок** открывается из профиля: подложка цвета кузова машины
  с узором из кубов — во всю ширину листа, кнопки «Улучшить» (пока отключена)
  и «Отправить» на стекле, название с кнопками «поделиться» и «скопировать
  ссылку», таблица и «Закрыть». Цены на карточках профиля нет: она имеет смысл
  только на витрине, поэтому `buildGift` строит её по флагу.

Высоту подложки задаёт содержимое, а не `aspect-ratio`. От выведенной через
`aspect-ratio` высоты проценты у детей разрешаются ненадёжно: подарок сперва
не влезал, а после попытки растянуть его по ряду — выдавливал кнопки за край.
Размер подарка теперь берётся долей от ширины, которая определена всегда.

Какой лист открывать, карточка не решает — ей это передают при сборке
(`buildGift(gift, onPick)`).

## Анимации карточек

Каждая карточка заводит свою анимацию сама, через `playWhenSeen()`: плеер
создаётся, когда карточка показалась на экране. Раньше витрину обходил
отдельный сканер по сетке главной, и карточки профиля оставались пустыми —
их этот обход не видел.

Созданные плееры и наблюдатели лежат в общем реестре, а `releaseArt(узел)`
снимает всё, что жило внутри выбрасываемой разметки. Без этого переключение
разделов в профиле копило бы плееры на узлах, которых уже нет в документе.

## Стекло

Класс `.glass` — полупрозрачная подложка, `backdrop-filter` под ней и четыре
внутренние тени по краям: светлее сверху, глуше снизу. Ободок от них и читается
как стекло. Висит на переключателе профиля и на счётчике штук в листе.

`background-color` задан дважды: сначала обычной `rgba`, следом через
`color-mix`. Браузер без поддержки второй строки просто не применит её и
останется на первой.

## Шрифт

SF Rounded **Semibold** лежит в `fonts/` и подключён через `@font-face` в начале
`style.css`. Начертание одно, и диапазон весов указан целиком (`100 900`)
намеренно: иначе браузер доутолщал бы глифы там, где в стилях стоит 700.
Побочное следствие — разницы в насыщенности между заголовком и подписью нет,
весь текст одного веса. Понадобится градация — положить рядом Regular и
развести их по `@font-face` с реальными весами.

## Локальный просмотр

Фронт без сервера открывается любым статическим сервером:

```bash
python3 -m http.server 5173
```

Тогда `/api/boot` недоступен, и приложение возьмёт `data/content.json`. Вне
Telegram будет «Гость»: подписи Telegram в браузере нет.

## Деплой

Продакшн: https://gopsgift.vercel.app (проект Vercel `gopsgift`).

Framework preset «Other», build command пустой, output directory — корень.
Функции из `api/` Vercel собирает сам. Переменные окружения (`BOT_TOKEN`,
доступ к Redis) подхватывает только **новый** деплой — после их правки нужен
передеплой.

## Привязка к боту

1. @BotFather → `/mybots` → бот → **Bot Settings** → **Menu Button** → указать URL с Vercel.
2. Либо `/newapp` для отдельного Mini App с прямой ссылкой.

Fullscreen включается автоматически в Telegram-клиентах с Bot API 8.0 и выше.
На старых версиях приложение просто открывается в обычном режиме.

## Токен бота

В репозитории его нет и быть не должно. Токен нужен только серверной части —
храни его в переменных окружения (`.env` локально, Environment Variables в
Vercel). Если токен попал в чат, переписку или коммит — отзови его через
@BotFather (**API Token** → **Revoke current token**).
